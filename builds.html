Oct 28 midday build: record bookmarks, a watch-size glance, this diary

2026-10-28

What changed

  • The record now carries a daily waypoint that sums up everything before it, so very old entries can one day be packed away without losing proof.
  • Corrections can now be added to an earlier entry without changing it; the note points at the original.
  • When the system was paused and catches up later, the first late entry now says so.
  • A tiny Glance page for a watch lists the Keeper, the Marked, today's twist, when the site was last updated and any trouble.
  • This Build diary page, written from each build's notes.

How it was tested

  • A full 69-day practice run passed with every daily waypoint checking out, plus the full record check and every site check.
  • A practice correction and a practice pause were added and checked, and a tampered waypoint was caught.

How to undo it

  • Every replaced piece was saved first and can be copied back in one step; no earlier entry was changed, so nothing in the record needs undoing.
